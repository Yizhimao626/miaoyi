# 喵艺升级蓝图：地基 → 盖楼

> 基于 2026-09-24 三路调研（GitHub 开源项目 / 头部产品 UX / 技术栈实践），结合喵艺现状整理。
> 原则：先打地基（架构与合规），再盖楼（产品功能），每阶段独立可验收。

---

## 一、调研来源摘要

### 开源项目（GitHub）
| 项目 | 定位 | 借鉴点 |
|---|---|---|
| SillyTavern | 本地角色扮演前端事实标准（数万 star） | World Info 记忆条目：关键词触发 + sticky（触发后持续 N 轮）/ cooldown（冷却）/ delay 时序状态机 + token 预算分配 |
| Open-LLM-VTuber | 离线语音 AI 伴侣（12.6k star） | **双通道输出**：内心想法只显示不朗读，口语才走 TTS |
| N.E.K.O. 猫娘计划 | 中文桌面猫娘（2k+ star） | UI / 大脑 / 记忆服务器三分离，记忆跨场景延续 |
| Muice-Chatbot 沐雪 | 中文主动伴聊 | 可配置概率主动话题 + 生活化触发 |
| Project AIRI | 开源 Neuro-sama | 多 Stage 共享同一"大脑"，插件系统 |

### 产品机制（Replika / Character.AI / 星野 / 豆包）
- **关系系统**：Replika 30 级 XP + 关系模式切换；星野友好度分级解锁剧情/羁绊任务 → 喵艺可做"关系阶段跃迁+专属剧情"
- **记忆透明化**：Replika 记忆仪表盘（查看/编辑/删除）；星野"事件簿"绑定记忆永不遗忘 → 记忆卡片流
- **情感沉淀**：Replika AI 第一人称日记；星野"那年今日"；Talkie 记忆卡牌 → 猫咪日记+回忆相册
- **语音拟真**：豆包实时语音 = 可打断 + 情绪起伏 + 停顿=思考，比音色数量更重要
- **用户痛点警示**：记忆差、回复雷同、更新后人设漂移 → 记忆可靠性+回复多样性应为第一优先级
- **付费红线**：核心陪伴免费，勿学星野"查看备忘录也收费"（被官媒点名）

### 技术栈（2024-2026 实践）
- **记忆**：mem0（事实抽取+过期退休+混合检索）最适合增量升级；Zep 图谱适合"偏好变化"类时间推理
- **Prompt**：原型锚定优于形容词堆叠（一致性 3-5 轮 → 40+ 轮）；Persona Persistence 周期重注入；历史压缩为人设相关摘要
- **TTS**：CosyVoice2 流式首包 ~150ms（阿里系，与 DashScope 同源，instruct 控情绪）；IndexTTS2 情感/音色解耦最强；GPT-SoVITS 保留做音色微调
- **成本**：prompt 缓存（静态前缀在前）TTFT 降 ~80%；大小模型路由（寒暄走 turbo，情感走 max）；语义缓存仅限白名单（防千篇一律）
- **主动 Agent**：心跳（定时检查，无事静默）+ 事件触发双通道；噪音预算 ≤3 次/小时 + 免打扰时段
- **合规**：⚠️ 《人工智能拟人化互动服务管理暂行办法》2026-07-15 已施行——AI 标识、防沉迷 2 小时提醒、未成年人模式、危机干预为硬性要求

## 二、喵艺现状 vs 差距分析

### 已有基础（不需要重做）
- 后端：FastAPI + JWT 双 token（15min/7d，token_type 校验）+ 限流 + 输入过滤 + 文件鉴权路由
- 对话：30 维情感引擎、意图分析、风格模仿、AIGC 输出审核（_moderate_output）、LLM 失败兜底
- 记忆：四层（工作/情景/语义/用户画像）+ RAG + mem0 式冲突解决 + 睡眠时整理 + 三因子排序
- 语音：GPT-SoVITS 本地 + 在线音色、分段合成续播、Silero VAD barge-in 打断、回声抑制
- 产品：亲密度等级、签到、主动聊天（概率+记忆触发+纪念日）、表情包、导出、管理后台

### 差距（对照调研结论）
| 领域 | 差距 | 对应借鉴 |
|---|---|---|
| 合规 | 缺 AI 标识、防沉迷提醒、未成年人模式、危机干预 | 2026-07-15 新规（硬性） |
| 人设一致性 | 无漂移检测；历史 30 轮无压缩；prompt 非原型锚定写法 | Persona Persistence + 原型锚定 |
| 记忆 | 无时间戳/退休机制；无用户侧记忆管理 UI | mem0 退休 + Replika 仪表盘 |
| TTS | GPT-SoVITS 非流式首包秒级；情感参数未直通语音 | CosyVoice2 流式 ~150ms |
| 输出 | 单通道（口语=内心），无内心戏 | Open-LLM-VTuber 双通道 |
| 关系 | 只有数值等级，无阶段/剧情 | Replika/星野阶段跃迁 |
| 成本 | 无缓存、无模型路由，全走大模型 | prompt 缓存 + 路由 |
| 主动聊天 | 概率+记忆触发，无作息表/生活模拟 | 沐雪 + 心跳纪律 |
